# Security Policy

Maintainer: **Daniel G. Cosenza from FNX Labs**.

## Scope

This repository generates and deploys the public GitHub Pages catalog at
<https://dgcosenza.github.io/> summarizing the container images published under
`github.com/dgcosenza/*-docker`. It contains no runtime secrets, credentials, or
infrastructure-specific data.

## Reporting a Vulnerability

Please report security issues privately via GitHub Security Advisories at
<https://github.com/dgcosenza/dgcosenza.github.io/security/advisories/new>.
For vulnerabilities affecting an individual container image, report them on that
image's `*-docker` repository.
